# Timer

Un temporizador sencillo hecho con HTML, CSS y JavaScript.

## Descripción

Este proyecto muestra un temporizador en la página y cuenta hacia atrás desde 20 segundos hasta cero. Cuando termina la cuenta, muestra un mensaje de finalización y detiene el intervalo.

## Archivos

- `index.html` — estructura de la página
- `styles.css` — estilos del contenedor del temporizador y del tema oscuro
- `script.js` — lógica del conteo regresivo

## Cómo ejecutarlo

1. Abre `index.html` en un navegador.
2. El temporizador comenzará automáticamente.
3. La página mostrará el tiempo restante cada segundo hasta llegar a cero.

## Notas

- El valor inicial predeterminado es 20 segundos.
- El proyecto no usa dependencias externas ni herramientas de compilación.
